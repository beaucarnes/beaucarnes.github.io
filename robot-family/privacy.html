Privacy Policy

Robot Family Uploads · last updated November 21, 2026

What this app is

Robot Family Uploads is a private, single-user tool written and operated by Beau Carnes. It publishes finished animated episodes to the Robot Family YouTube channel, which Beau owns. It is not offered to the public and has no users other than its developer.

Google user data it accesses

The app uses the YouTube Data API with the youtube.upload and youtube scopes, for exactly two purposes:

  • uploading video files, titles, descriptions and tags to the developer's own channel;
  • setting a custom thumbnail on those uploads.

It does not read subscriber lists, comments, analytics, watch history or any data belonging to other YouTube users.

How data is stored and shared

  • The only Google data the app stores is its own OAuth token, kept in a file on the developer's computer so it does not have to sign in for every upload.
  • No Google user data is sent to, sold to, or shared with any third party, and none is used for advertising or model training.
  • The app runs on the developer's own machines; there is no server, database or analytics.

Deleting data

Deleting the token file, or revoking the app's access at myaccount.google.com/permissions, removes all stored Google data.
